# 🌐 AI Portfolio Website

A modern, responsive portfolio website showcasing my projects, technical skills, and experience in Artificial Intelligence, Machine Learning, Computer Vision, and Full-Stack Development.

**🌍 Live Demo:** https://ayan-portfolio-tau-eight.vercel.app/

---

## 📌 Overview

This portfolio was built to present my work, highlight my technical expertise, and provide an easy way for recruiters, clients, and collaborators to learn more about me.

The website features a modern UI with smooth animations, responsive layouts, and fast performance.

---

## ✨ Features

* Responsive design for desktop, tablet, and mobile
* Modern dark theme UI
* Smooth animations using Framer Motion
* Projects showcase
* Technical skills section
* About Me section
* Contact section
* Resume download
* Fast deployment with Vercel

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Maybeayan07/ayan-portfolio.git
```

Move into the project directory:

```bash
cd ayan-portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
